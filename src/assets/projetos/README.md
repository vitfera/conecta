# Capas das histórias de projetos

Capturas das primeiras telas públicas, inspecionadas antes da inclusão. Mostram somente o cabeçalho e a apresentação das plataformas, sem áreas autenticadas ou perfis individuais.

| Arquivo                            | Origem                                 |
| ---------------------------------- | -------------------------------------- |
| `campo-mourao-mapas-culturais.png` | <https://mapas.campomourao.pr.gov.br/> |
| `cianorte-mapas-culturais.png`     | <https://cultura.cianorte.pr.gov.br/>  |

Dimensões: **1440 × 600 px**, proporção **12:5**. O componente `ProjectCover.astro` associa a imagem ao slug do Markdown e gera versões WebP. Uma capa ausente usa uma composição decorativa própria, sem imagem quebrada.

As marcas e o conteúdo presentes nas capturas pertencem às respectivas plataformas e instituições. As imagens documentam os projetos apresentados; não representam autoria da Conecta sobre o software livre Mapas Culturais.
