# Foto de Victor Ferreira

A foto exibida em Quem Somos já está nesta pasta. Para substituí-la, mantenha o nome exato **`victor-ferreira.jpg`** e siga as especificações abaixo.

- Proporção: **3:4, vertical**.
- Dimensão recomendada: **900 × 1200 pixels**.
- Formato: JPEG, extensão `.jpg` em minúsculas.
- Enquadramento: rosto centralizado, com alguma folga acima da cabeça.

Caminho no projeto: `src/assets/equipe/victor-ferreira.jpg`.

O componente `src/components/ProfilePortrait.astro` carrega esse arquivo e gera versões WebP responsivas. A substituição é refletida na prévia do Astro. Para atualizar o site publicado, gere e publique um novo build.

O quadro do retrato preserva o espaço vertical durante o carregamento da imagem.
