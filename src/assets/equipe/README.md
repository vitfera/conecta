# Foto de Victor Ferreira

Coloque a foto real nesta pasta com o nome exato **`victor-ferreira.jpg`**.

- Proporção: **3:4, vertical**.
- Dimensão recomendada: **900 × 1200 pixels**.
- Formato: JPEG, extensão `.jpg` em minúsculas.
- Enquadramento: rosto centralizado, com alguma folga acima da cabeça.

Caminho no projeto: `src/assets/equipe/victor-ferreira.jpg`.

O componente `src/components/ProfilePortrait.astro` detecta esse arquivo e substitui o espaço reservado na página Quem Somos. Não é necessário editar o código. Na prévia do Astro, a adição do arquivo atualiza a página; para o site publicado, gere e publique um novo build.

O build otimiza a imagem e preserva o espaço vertical para evitar saltos no layout. Enquanto a foto não estiver disponível, aparece apenas uma composição com as iniciais de Victor, sem foto genérica.
